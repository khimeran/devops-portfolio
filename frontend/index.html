Git — система контроля версий

Git запоминает каждое изменение файлов. Как "сохранение игры" — можно вернуться к любой точке.

Основные команды

git add README.md
         # добавить файл в список для сохранения
  git commit -m "описание"  #
  создать сохранение с описанием
  git push                 #
  отправить на GitHub
  git remote -v            #
  показать адрес удалённого репозитория

Docker Compose

Файл docker-compose.yml описывает все сервисы проекта. Один файл — весь стек.

Сервисы и их порты

backend    → localhost:8000   # FastAPI API
  db         → localhost:5432   # PostgreSQL
  redis      → localhost:6379   # Redis (кэш)
  prometheus → localhost:9090   # Метрики
  grafana    → localhost:3030   # Дашборды

Основные команды

docker compose up
  --build  # запустить всё (с пересборкой)
  docker compose down        #
  остановить и удалить контейнеры
  docker ps                  #
  список запущенных контейнеров
