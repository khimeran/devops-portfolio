🐧 Linux: ФС, бинарники, симлинки

Базовый блок Linux. Что лежит в системных папках, как ОС запускает программы, что такое ELF и симлинки.

Главное

/bin, /sbin, /lib, /lib64 — симлинки на /usr/* (/usr merge)
file /usr/bin/ls     — тип файла: ELF 64-bit, dynamically linked
ldd /usr/bin/ls      — список .so зависимостей
readlink -f /bin    — куда указывает симлинк
ls -la              — первая буква = тип файла
                          (l симлинк, d папка, - файл)

Запомнить

Dynamic linking — программа зовёт .so из системы, не носит код в себе.
ld-linux-x86-64.so.2 — динамический линкер, стартует ПЕРВЫМ.
LD_PRELOAD — впрыснуть свою .so; SUID-программы её игнорируют.
Symlink — указатель с путём, может умереть.
Hard link — второе имя того же inode, неуязвим к удалению оригинала.

Git — система контроля версий

Git запоминает каждое изменение файлов. Как "сохранение игры" — можно вернуться к любой точке.

Основные команды

git add README.md
         # добавить файл в список для сохранения
  git commit -m "описание"  #
  создать сохранение с описанием
  git push                 #
  отправить на GitHub
  git remote -v            #
  показать адрес удалённого репозитория

Docker Compose

Файл docker-compose.yml описывает все сервисы проекта. Один файл — весь стек.

Сервисы и их порты

backend    → localhost:8000   # FastAPI API
  db         → localhost:5432   # PostgreSQL
  redis      → localhost:6379   # Redis (кэш)
  prometheus → localhost:9090   # Метрики
  grafana    → localhost:3030   # Дашборды

Основные команды

docker compose up
  --build  # запустить всё (с пересборкой)
  docker compose down        #
  остановить и удалить контейнеры
  docker ps                  #
  список запущенных контейнеров
