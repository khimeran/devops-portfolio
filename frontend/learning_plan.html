🐧 ФАЗА 1 · Linux + Bash

14 дней 7 модулей 🔥 фундамент

Сначала ФС, права, процессы, сервисы. Потом текстовая магия (grep/awk/sed) и сеть на уровне ОС. Финал — bash-скриптинг. После этой фазы ты сможешь администрировать любой Linux-сервер уверенно.

📦 Модуль 1.1 · Файловая система и навигация
2 дня
FHS (где что лежит). Симлинки. Поиск файлов через find, locate. Просмотр через cat/less/tail -f.
Д1/bin, /sbin, /lib, /lib64 + ELF, dynamic linking · симлинки · /usr merge
Бинарники vs библиотеки. file /bin/ls покажет ELF + dynamic linker. Первая буква l в ls -la = симлинк.
🛠 ls -la /bin /sbin, file /bin/ls, readlink -f /bin, ldd /bin/ls
Д2/etc, /var, /usr, /opt, /tmp, /root, /home, /proc, /sys, /dev, /run, /boot
Все остальные директории + навигация (find, locate, stat) + просмотр (cat, less, tail -f, cat -A).
🛠 Прочитать /etc/os-release, /etc/fstab; найти все .conf в /etc старше года; journalctl -f
🧪 тест 📝 «Структура ФС»
📦 Модуль 1.2 · Права и владение
2 дня
Числовая (755, 644, 600) и символьная (u+x) запись. SUID/SGID/Sticky. SELinux на Fedora — почему случаются «непонятные» отказы.
Д3chmod + chown + chgrp + umask
Числовая и символьная нотация. Шаблоны 755 / 644 / 600 / 700. Почему файлы рождаются с 644.
🛠 Создать файлы, поменять права/владельца, поиграться с umask
Д4SUID / SGID / Sticky + SELinux 🔥
Почему /usr/bin/passwd SUID. Почему /tmp sticky. Контексты SELinux (ls -Z), chcon, restorecon, getenforce.
🛠 Найти все SUID в /usr/bin; разобрать одно событие из /var/log/audit/audit.log
🧪 тест 📝 «Права, SELinux»
📦 Модуль 1.3 · Процессы и сервисы
2 дня
Жизнь процессов, сигналы, systemd. Свой systemd-сервис.
Д5ps/top/htop + сигналы + фон + tmux 🔥
SIGTERM (15) vs SIGKILL (9) vs SIGHUP (1 — reload). &, nohup, tmux для долгоиграющих задач.
🛠 Запустить sleep в фоне, убить разными сигналами; tmux-сессия + отключение/переподключение
Д6systemd + свой unit-файл 🔥
systemctl start/stop/restart/reload/enable. journalctl -u svc -f. Создать my-watch.service, который пишет дату каждую минуту.
🛠 Перезапустить docker, посмотреть логи; создать свой unit, активировать, проверить
🧪 тест 📝 «systemd, мой первый юнит»
📦 Модуль 1.4 · Текст и pipe-магия 🔥 КРИТИЧНО
3 дня
80% работы DevOps — парсить логи и фильтровать вывод. grep + awk + sed + pipe-цепочки — must-have.
Д7grep + regex
Флаги -i, -v, -r, -l, -n, -A/-B/-C. Regex: ., *, ?, ^, $, [abc], [0-9].
🛠 Найти ERROR в journalctl за сутки с контекстом; найти все IPv4 в логе
Д8awk + sed
awk: поля $1, $NF, -F. sed: замены s/old/new/g, -i in-place, удаление строк.
🛠 Из ps aux вывести только PID и команду; заменить «error» на «ERR» в файле
Д9Сборные команды + перенаправления
cut, tr, sort, uniq -c, xargs, tee. >, >>, 2>&1, &>.
🛠 Топ-10 IP по запросам из access.log одной длинной цепочкой
🧪 тест 📝 «Текстовая магия»
📦 Модуль 1.5 · Сеть на уровне ОС
1 день
ip/ss вместо ifconfig/netstat. DNS-диагностика. HTTP-диагностика. firewalld.
Д10ip + ss + dig + curl -v + nc + firewall-cmd
Свой IP, шлюз, открытые порты. dig +trace для DNS. nc -zv host port — реальная проверка порта (ping ≠ порт).
🛠 Показать свою сеть; dig +trace google.com; открыть-закрыть порт через firewalld
🧪 тест 📝 «Сетевая диагностика»
📦 Модуль 1.6 · Пакеты, юзеры, логи
1 день
Менеджеры пакетов, юзеры, точечный sudo, логи и logrotate.
Д11dnf + useradd + /etc/sudoers.d/ + логи
Установка пакетов, поиск (dnf provides). Создание пользователя с точечным sudo. /var/log/secure для SSH-логинов. logrotate.
🛠 Поставить htop; создать appuser с sudo на systemctl restart docker; найти неудачные SSH-логины
🧪 тест 📝 «Пакеты, юзеры, логи»
📦 Модуль 1.7 · Bash-скриптинг 🔥 САМОЕ ВАЖНОЕ
3 дня
Финальный модуль фазы. Переменные, условия, циклы, функции, обработка ошибок. В конце — рабочий health.sh.
Д12Переменные + условия + циклы
"/'/`, $(cmd). if [[ ]], тесты файлов (-f, -d, -r). for X in *.log, while read.
🛠 Скрипт-визитка (hostname/uptime/диск); скрипт-алерт «если место < 20%»; цикл по списку доменов с ping
Д13Функции + аргументы + strict mode + getopts
Функции, $1/$@/$#, коды возврата. set -euo pipefail, trap. Парсинг флагов через getopts, --help.
🛠 ./backup.sh -d /var -o /backups с проверкой обоих флагов
Д14Финальный health.sh + 3 скрипта проекта
Сборка всего из модуля: uptime, диск, RAM, top-5 процессов, проверка живости сервисов, JSON-вывод. Плюс backup_db.sh, cleanup_logs.sh, watchdog.sh.
🛠 Все скрипты с #!/usr/bin/env bash + set -euo pipefail + getopts + --help
🧪 тест 📝 «Bash-скриптинг: мои шаблоны»
