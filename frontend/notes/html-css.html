HTML и CSS

HTML описывает структуру страницы, CSS — её внешний вид. Браузер читает оба файла и рисует то что видит пользователь.

Аналогия: HTML — это скелет здания (стены, окна, двери). CSS — это дизайн интерьера (цвет стен, мебель, освещение). Без HTML нечего оформлять, без CSS всё выглядит как текст на белом фоне.

Структура HTML файла

HTML Базовая структура любой страницы 
<!DOCTYPE html>
<!-- DOCTYPE — говорим браузеру что это HTML документ -->

<html lang="ru">
<!-- html — корневой элемент, lang — язык страницы -->

<head>
  <!-- head — служебная информация, не видна пользователю -->
  <meta charset="UTF-8">
  <!-- charset — кодировка, UTF-8 поддерживает русские буквы -->

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <!-- viewport — страница нормально выглядит на телефоне -->

  <title>Название вкладки</title>
  <style> ... </style>
  <!-- style — CSS стили внутри HTML файла -->
</head>

<body>
  <!-- body — всё что видит пользователь -->
  <h1>Заголовок</h1>
  <p>Параграф текста</p>
  <div>Блок-контейнер</div>
  <span>Строчный элемент</span>
  <a href="page.html">Ссылка</a>
</body>
</html>

Основные CSS свойства

CSS Цвет, шрифт, отступы 
body {
  background: #0d1117;   /* цвет фона */
  color: #e6edf3;        /* цвет текста */
  font-family: sans-serif; /* шрифт */
  padding: 2rem;         /* отступ внутри элемента */
  margin: 0 auto;        /* центрировать по горизонтали */
  max-width: 900px;      /* максимальная ширина */
}

h1 {
  font-size: 2rem;       /* размер шрифта */
  font-weight: bold;     /* жирный */
  border-bottom: 1px solid #30363d; /* линия снизу */
}
CSS Flexbox — расположение элементов 
.container {
  display: flex;                  /* включить flexbox */
  justify-content: space-between; /* элементы по краям */
  align-items: center;            /* выровнять по центру вертикально */
  gap: 1rem;                      /* расстояние между элементами */
}

/* sidebar + content — два блока в строку */
body {
  display: flex;    /* sidebar слева, content справа */
  height: 100vh;    /* на весь экран (vh = viewport height) */
}
.sidebar { width: 220px; flex-shrink: 0; }
.content  { flex: 1; }  /* занять всё оставшееся место */

Типы блоков

CSS display: block vs inline 
/* block — занимает всю ширину строки, следующий элемент на новой строке */
div, h1, h2, p, pre { display: block; }

/* inline — занимает только место текста, элементы идут в строку */
span, a, code, strong { display: inline; }

/* inline-block — как inline но можно задать ширину и высоту */
.badge { display: inline-block; padding: 0.2rem 0.7rem; }
Запомни: каждый HTML тег нужно закрыть — <div> закрывается </div>. Исключения: <meta>, <input>, <br> — самозакрывающиеся теги.

IntersectionObserver — отслеживание видимости

Браузерный API который следит за тем, какой элемент сейчас виден на экране. Мы используем его для scroll spy — автоматического переключения активного пункта в меню при прокрутке.

JAVASCRIPT Scroll spy в notes.html 
const sections = document.querySelectorAll('section');
// querySelectorAll — найти все элементы на странице по селектору
// 'section' — все теги <section>

const observer = new IntersectionObserver(entries => {
// IntersectionObserver — создать наблюдателя
// entries — список элементов которые изменили видимость

  entries.forEach(entry => {
  // forEach — пройти по каждому изменению

    if (entry.isIntersecting) {
    // isIntersecting — элемент сейчас виден в области просмотра

      const id = entry.target.id;
      // target — сам элемент, id — его атрибут id (например "git")

      links.forEach(l => l.classList.remove('active'));
      // убрать выделение у всех ссылок

      const active = document.querySelector(`.sidebar a[href="#${id}"]`);
      // найти ссылку в меню которая ведёт на этот раздел
      // [href="#git"] — ссылка с атрибутом href равным "#git"

      if (active) active.classList.add('active');
      // добавить выделение найденной ссылке
    }
  });

}, { rootMargin: '0px 0px -70% 0px', threshold: 0 });
// rootMargin — сжимаем область срабатывания:
//   '0px 0px -70% 0px' = сверху 0, справа 0, снизу -70%, слева 0
//   срабатывает когда верх секции входит в верхние 30% экрана
// threshold: 0 — срабатывать как только хоть пиксель виден

sections.forEach(section => observer.observe(section));
// observe — начать наблюдать за каждой секцией
Scroll spy не переключается на длинных разделах

Причина: threshold: 0.3 требует что 30% элемента видно. Для длинных разделов это может не выполняться никогда.

Решение — использовать rootMargin вместо threshold
{ rootMargin: '0px 0px -70% 0px', threshold: 0 }
// threshold: 0 — срабатывает при любой видимости
// rootMargin -70% снизу — активируется когда верх секции
// попадает в верхние 30% экрана
